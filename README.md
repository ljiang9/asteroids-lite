# asteroids-lite

极简小行星游戏：飞船推进 / 转向 / 开火，小行星被击中后分裂（大→中→小），
环绕边界（飞出左边界从右边回来），撞上小行星掉命。

纯标准库（`argparse` / `sys` / `random` / `math`），无第三方依赖。

## 玩法

- `a` 左转，`d` 右转，`w` 推进，`s` 开火，`q` 退出（每行一个命令，回合制）
- 击碎小行星得分：大 20 / 中 50 / 小 100
- 3 条命；清光所有小行星判胜

## 用法

```bash
python3 -m asteroids_lite            # 交互模式（需要终端）
python3 -m asteroids_lite --auto     # 无头自动演示
python3 -m asteroids_lite --auto --frames 1000 --seed 42 --verbose
```

## 设计取舍

- 碰撞用圆形近似；边界环绕用取模实现，简单可靠
- AI 很简单：转向朝最近小行星开火、太近就逃离——演示用，非最优玩家
- 交互是回合制（每行一个命令），不是实时动作游戏；实时版需要 curses 接按键事件

## 真实验证记录

- `py_compile` 通过
- 单元测试：子弹命中大行星分裂成 2 个中行星且 +20 分；中行星→2 小（+50）、小行星直接消失（+100）；双子弹同帧命中同一颗只分裂一次；飞船飞出右边界从左边回来；小行星撞飞船掉 1 命并重生；`thrust()` 改变速度矢量；子弹过期消失；清光判胜——全部通过
- 修过的真 bug：`_collide_bullets` 用 `size=0` 标记待删除小行星，同一帧第二颗子弹再读其 `radius` 报 `KeyError`；已改为索引集合标记，回归测试覆盖
- `--auto --frames 600 --seed 42`：正常结束（得分 900，演示 AI 较弱、3 命耗尽属正常）
- 10 个种子各 600 帧：全部无崩溃正常结束（3 胜 7 负，AI 只是演示用）

## 已知局限

- 无实时键盘输入，只有 `--auto` 无头演示和回合制交互
- AI 不躲子弹之外的威胁，偶发被撞；无最高分存档、无关卡
- 需要 Python 3.10+
